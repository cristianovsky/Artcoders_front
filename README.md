# Artcoders Frontend  

Este proyecto es  para el desarrollo del frontend del proyecto **Misión TIC - Ciclo 4 UdeA 2021**. Está diseñado para ser una base sólida y escalable, permitiendo a los desarrolladores centrarse en construir funcionalidades específicas.  

El proyecto consiste es un sistema que te permite gestionar todos los proyectos llevado a cabo en la Udea, permitiendo actualizar y tener el seguimiento de todo lo realizados por los estudiantes y profesores 

El frontend se desarrolla utilizando **React** para crear interfaces dinámicas y modernas, complementado con **Tailwind CSS** para un diseño estilizado, limpio y altamente personalizable.  

---

## Tecnologías utilizadas  

El proyecto incluye las siguientes tecnologías principales:  

- **React**: Biblioteca de JavaScript para construir interfaces de usuario basadas en componentes reutilizables.  
- **Tailwind CSS**: Framework CSS basado en utilidades que facilita la creación de diseños responsivos y modernos sin necesidad de escribir CSS personalizado en cada componente.  
- **JavaScript ES6+**: Se utiliza sintaxis moderna para garantizar un código limpio y eficiente.  
- **Node.js + Yarn**: Herramientas utilizadas para la gestión de dependencias y scripts de desarrollo.  

---

## Características  

### Diseño responsivo  
La interfaz está diseñada para adaptarse automáticamente a diferentes tamaños de pantalla, garantizando una experiencia de usuario óptima en dispositivos móviles, tabletas y escritorios.  

### Estructura modular  
El proyecto está organizado en módulos, con una estructura de carpetas clara que facilita la escalabilidad y el mantenimiento.  

### Configuración personalizada  
La configuración de **Tailwind CSS** está disponible en el archivo `tailwind.config.js`, permitiendo adaptarla según las necesidades del proyecto.  

### Rápido inicio  
Con las dependencias y scripts preconfigurados, puedes comenzar a desarrollar de inmediato.
